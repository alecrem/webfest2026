上から順にやらなくてよい。気になったものを、すきなだけ試そう。 こまったら 🗑️ 最初にもどす を押せば、テンプレートに戻れる。

1ポケモンの番号を変える

<poke-card
  src="/api/pokemon/25"
  color="#ffde00"
  title="お気に入りポケモン"
></poke-card>

25 の数字を 1〜1025 の好きな番号に変えてみよう。全然ちがうポケモンが出る。

2色を変える

color="#ffde00" の #ffde00 の左に小さな四角 (色スウォッチ) がある。 クリックすると色えらびが開くので、好きな色を選ぶ。16進の文字は自動で書きかわるので、 覚えたり計算したりしなくてOK。

<style> の中の色 (背景の色・文字の色・タイトルの色など) にも同じ色スウォッチが 付いている。コメントを見れば、それが何の色か分かる。

3見出し (title) を変える

<poke-card
  src="/api/pokemon/25"
  color="#ffde00"
  title="お気に入りポケモン"
></poke-card>

title="お気に入りポケモン" の文字を、自分の好きな見出しに変えてみよう。 カードの上の色帯に、その文字が出る。

4自分の部活に変える

テンプレートには最初 kitaku (帰宅部) が入っている:

<club-list
  src="/api/bukatsu/kitaku"
  color="#16a34a"
  title="私の部活"
></club-list>

kitaku を、下の表から自分の部活の id に変えてみよう。

5同じデータを、ちがう聞き方でもらう

バックエンドは、同じ種類のデータでも「アドレスの書き方」で答えが変わる。 部活 (bukatsu) で3つの聞き方を試してみよう:

  • 1件だけ: /api/bukatsu/kitaku
  • ぜんぶの一覧: /api/bukatsu
  • 条件でしぼった一覧: /api/bukatsu?category=文化部

右上の「バックエンドをのぞく →」で、この3つのアドレスを順番に送信して、 返ってくるデータがどうちがうか見くらべてみよう。多くのバックエンドは、こんなふうに 「1件」「一覧」「しぼりこみ (?○○=)」を用意している。

気に入ったアドレスは、そのまま <club-list> の src="..." に貼ればOK。

6掛け持ちの部活をまとめて出す

2つ以上の部活に入っている人は、ids にカンマ区切りで並べると、 1枚のカードにまとめて出せる:

<club-list
  src="/api/bukatsu?ids=yakyu,bijutsu"
  color="#2f4135"
  title="私の部活"
></club-list>

同じやり方は、ポケモンやチームでも使える:

<poke-card src="/api/pokemon?ids=25,6,9" title="お気に入り"></poke-card>
<team-card
  src="/api/npb/teams?ids=hawks,giants"
  title="応援しているチーム"
></team-card>

<team-card src="/api/npb/teams/hawks" title="応援しているチーム"></team-card>

<team-card

  title="応援しているチーム"

8タイプやリーグで一覧を出す

<poke-card src="/api/pokemon?type=ほのお" title="ほのおタイプ"></poke-card>
<team-card
  src="/api/npb/teams?league=セ・リーグ"
  title="セ・リーグ"
></team-card>

ポケモンのタイプ: ほのお・みず・でんき・くさ・こおり・かくとう・どく・じめん・ひこう・ エスパー・むし・いわ・ゴースト・ドラゴン・あく・はがね・フェアリー・ノーマル。

9「バックエンドをのぞく」で自分でアドレスを試す

右上の「バックエンドをのぞく →」を押すと、別タブでバックエンドの練習ページが開く。 アドレス (例: /api/pokemon/25) を書きかえて「送信」を押すと、バックエンドが返すデータが そのまま見られる。レシピに出てくるアドレスを ここで先に試してから、自分のページに貼るのもよい。

下の「📡 このページの通信」パネルにも、自分のページが実際に呼んだアドレスが出る。 クリックすると同じように別タブで開ける。

10(発展) 自己紹介や見出しを増やす

<h1>⭐ わたしのページ ⭐</h1>
<p>ここに自己紹介を書こう！</p>

<h1> の中の文字や絵文字を変えたり、<p> をもう1つ増やして自己紹介を 書き足したりしてみよう。ウィジェットの <poke-card> や <team-card> を コピーして、もう1つ増やすこともできる (同じタグを2回書いてOK)。

11(発展・時間があれば) 自分で fetch を書く

ウィジェットを使わずに、バックエンドから直接データをもらうこともできる:

<p id="my-pokemon">読み込み中…</p>
<script>
  fetch("/api/pokemon/1")
    .then((r) => r.json())
    .then((p) => {
      document.getElementById("my-pokemon").textContent = p.nameJa;
    });
</script>

「バックエンドをのぞく」で試したアドレスを fetch("...") の中に入れて、 p. の後ろを nameJa や sprite に変えると、いろいろなデータが取り出せる。
